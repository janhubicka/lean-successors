\item\label{item:boringage} \emph{No age change:}
		For every $\type{S}_0\in S$ and every finite ordered $L$-structure
		$\str{A}$ whose vertex set is a finite subset of $\omega$ containing
		$\ell+1$, assume that
		\begin{enumerate}
			\item $\str{A}\restriction_{\ell+1}=
				\str{f(\type{S}_0)}\restriction_{\ell+1}$, and
			\item for every $i\in A$ with $i>\ell$ there is a
				$\type{S}_i\in S$ such that
				$\typev^{\ell+1}_{\str{A}}(i)=\str{f(\type{S}_i)}$.
		\end{enumerate}
		Then whenever some $\str{F}\in\mathcal F$ admits an ordered embedding
		into $\str{A}$, some $\str{F}'\in\mathcal F$ admits an ordered
		embedding into $\str{A}\restriction_{A\setminus\{\ell\}}$.
