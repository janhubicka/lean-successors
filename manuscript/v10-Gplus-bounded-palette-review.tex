The actual Kpt forest has finitely many nodes at every finite level.
\texttt{GPlusBoundedPalette.lean} uses the already verified generic
\texttt{SMTree.InitialNode} finiteness result to prove that genuine
strict representing pairs $(S,T)$ with $\ell(T)\le b$ form a finite

representing pairs form an explicitly finite palette. This is a
coarse palette before imposing injectivity or the induced ordered
type of a prescribed finite structure, so those restrictions will
also be finite once represented inside this set.
This statement does NOT assume that the verified numerical envelope
bound itself produces a bounded representing pair for every required
vertex: the geometric envelope-coverage and exact approximation-domain
